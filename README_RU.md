# Баланс ПриватБанк — Android-виджет

Простой проект Android-приложения, которое читает уведомления ПриватБанка локально на телефоне и ищет остаток в формате `Бал. 149 930.61₴`. На рабочем столе виджет показывает баланс и изменение относительно предыдущего распознанного баланса. Кредитный лимит не отображается.

## Важно
- Это исходный проект, а не готовый APK. APK собирается через GitHub Actions.
- Пока это первая версия; её нужно проверить на реальных уведомлениях и конкретной версии приложения Приват24.
- Приложение не запрашивает логин/пароль и не отправляет данные в интернет.
- Для работы Android попросит включить доступ к уведомлениям. Этот доступ позволяет службе видеть уведомления других приложений, поэтому включайте его только если доверяете собранному вами APK.
- В коде предусмотрен фильтр имени пакета, содержащего `privat`. Если официальное приложение использует другой идентификатор пакета, фильтр потребуется изменить.

## Как собрать APK с телефона
1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки.
2. Откройте вкладку **Actions** репозитория.
3. Разрешите запуск GitHub Actions, если GitHub спросит.
4. Запустите workflow **Build APK** (или он запустится после push в `main`).
5. Откройте завершённый запуск workflow и скачайте artifact `PrivatBalanceWidget-debug-apk`.
6. Распакуйте artifact ZIP: внутри будет `app-debug.apk`.
7. На телефоне разрешите установку приложения из источника, которым скачан APK, и установите его.
8. Откройте приложение, нажмите «Включить доступ к уведомлениям», включите «Баланс ПриватБанк».
9. На рабочем столе зажмите пустое место → **Виджеты** → **Баланс ПриватБанк** и добавьте виджет.

## Проверка
После добавления виджета дождитесь следующего уведомления ПриватБанка, в котором есть строка `Бал.`. Первая сумма задаёт начальный баланс; изменение появится после следующего уведомления с новым балансом.

## Ограничения первой версии
- Виджет обновляется только при поступлении подходящего уведомления с балансом; он не запрашивает баланс у банка.
- Если уведомления отключены, приложение не сможет обновлять данные.
- Значение изменения считается как разница между двумя последними распознанными остатками. Если уведомления пропущены, разница может включать несколько операций.
